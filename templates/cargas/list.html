Obligatoria Titulo

  • Titulo — obligatorio; identifica la carga (el # lo asigna la plataforma)
  • Tipo — opcional. Códigos del sistema o texto libre (si no coincide, se guarda como «Otro»)
  • Prioridad — opcional (BAJA, MEDIA, ALTA; si no coincide, MEDIA)
  • Descripcion — opcional
  • Proyecto (también URL) — opcional; listado de proyecto
  • Asignado, Cliente, ID Orden — opcionales; déjalos vacíos si no aplican

  • Solo Titulo es obligatorio. Asignado, Cliente e ID Orden son opcionales.
  • El número (#) de cada carga lo genera automáticamente la plataforma.
  • Duplicados se detectan solo por Título; no se sobrescriben.
  • Proyecto / URL guarda el listado de proyecto y abre el filtro de OT.
  • Si Completas Asignado/Cliente/ID Orden, deben existir en el sistema; si no, deja la celda vacía.
  • Tipos como «Actualización Ajuste Tarifario» se aceptan: quedan como Otro y el texto se conserva en la descripción.
