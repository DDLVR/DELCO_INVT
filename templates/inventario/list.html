Guía de Formato para Importación
Pasos rápidos para subir archivos
  1. Descarga la plantilla desde Exportar Excel del tipo que quieras cargar.
  2. Completa las columnas respetando el orden exacto de cada sección.
  3. Guarda el archivo en formato .xlsx.
  4. Usa el botón Importar Excel.
  5. Si hay errores, corrige desde el resumen de errores y reintenta.
Formato requerido (11 columnas)

Orden exacto: #, Fecha Recepción, Bodega, Marca, Caja, Medidor, Módulo, Fecha Entrega, Entregado A, Estado, Cliente

Obligatorio: Fecha Recepción y Medidor (serie).
Estados válidos: En bodega, Instalado, Retirado, En reparación, Dado de baja.
Recomendación: no cambies el orden de columnas. Puedes dejar campos no obligatorios vacíos.
Formato requerido (11 columnas)

Orden exacto: IMEI, OPERADOR, ABONADO, DIRECCIÓN IP, APN, FECHA RECEPCIÓN, ENTREGADO A, FECHA ENTREGA, ESTADO, CLIENTE, MEDIDOR

Obligatorio: IMEI.
Cliente: usar número de cliente (si no existe, se crea automáticamente).
Los datos importados se pueden completar/ajustar desde el modal de modificar.
Formato requerido (18 columnas)

Orden exacto: MARCA, MODELO, IMEI, SERIE, Fecha Recepción, Fecha Entrega, Caja, Técnico Responsable, Cliente, Medidor, IP, Puerto, Marca, Obs, Retirado, Serie, Irregularidad, Proyecto

Obligatorio: MARCA y SERIE.
Importante: no mover columnas ni cambiar encabezados.
Lo azul en plantilla se puede editar luego en el módulo de modificación.
Buenas prácticas:
  • Usa una fila por equipo.
  • No repitas IMEI o Serie.
  • Fechas aceptadas: DD-MM-YYYY, DD/MM/YYYY, YYYY-MM-DD.
  • No agregues fórmulas ni celdas combinadas.
