Guía de Formato para Importación
📏 Formato para Medidores
Objetivo: Los medidores se reciben en bodega y luego se entregan a técnicos para instalación.
🟢 Columnas del Excel (se importan)
Columna Campo Obligatorio Ejemplo
A Fecha Recepción Sí 15-01-2024 o 2024-01-15
B Bodega No Bodega Central
C Marca No Elster, Landis+Gyr
D Caja Sí CAJA-001
E Serie Sí MED-2024-001 (único)
F Módulo No Monofásico, Trifásico
🟡 Campos que completa el Administrativo (después)
  • Fecha Entrega: Cuando se entrega al técnico
  • Entregado A: Técnico que lo recibe
  • Estado: Bodega, Instalado, Reparación, etc.
  • Cliente: Cliente asociado
📱 Formato para SIM Cards
Sistema de 2 colores:
  • 🟡 AMARILLO: Datos del Excel (solo lectura en el sistema)
  • 🟢 VERDE: Datos que completa el administrativo
🟡 Columnas AMARILLAS del Excel (se importan - solo lectura)
Columna Campo Obligatorio Ejemplo
A IMEI Sí 867456789012345 (único)
B OPERADOR No Movistar, Entel, Claro
C ABONADO No 123456789012345
D DIRECCIÓN IP No 192.168.1.100
E APN No internet.movil
F FECHA RECEPCIÓN No 15-01-2024
G ENTREGADO A No Juan Pérez
🟢 Campos VERDES (editables por administrativo)
  • FECHA ENTREGA: Fecha de entrega/instalación
  • ESTADO: Estado actual de la SIM
  • CLIENTE: Cliente asociado (número de cliente)
  • MEDIDOR: Medidor asociado (serie del medidor)
Nota: Los campos amarillos NO se pueden modificar después de importar. Solo los campos verdes son editables en el sistema.
📡 Formato para Módems
Sistema de 3 colores:
  • 🟢 VERDE: Datos del Excel (solo lectura en el sistema)
  • 🟡 AMARILLO: Datos que completa el administrativo
  • 🟠 NARANJA: Datos ocultos (solo visibles para admin/auditor)
🟢 Columnas VERDES del Excel (se importan - solo lectura)
Columna Campo Obligatorio Ejemplo
A MARCA Sí Huawei, ZTE, Quectel
B MODELO No E3372, MF79, EC25
C IMEI No 867456789012345
D SERIE Sí HW-2024-001 (único)
E Fecha Recepción No 15-01-2024
F Fecha Entrega No 20-01-2024
G Caja No CAJA-101
H Técnico Responsable No Juan Pérez
🟡 Columnas AMARILLAS (editables por administrativo)
Columna Campo Descripción
I Cliente Número de cliente asociado
J Medidor Serie del medidor asociado
K Observaciones Notas adicionales
🟠 Columnas NARANJAS (ocultas para administrativo)

Estas columnas se importan pero NO son visibles para usuarios administrativos. Solo accesibles desde el panel de administración para superusuarios.

  • L - IP
  • M - Puerto
  • N - Marca Secundaria
  • O - Retirado
  • P - Serie Secundaria
  • Q - Irregularidad
  • R - Proyecto
Nota: Los campos verdes NO se pueden modificar desde el sistema. Solo los campos amarillos son editables. Los campos naranjas son solo de auditoría.
Notas Importantes
  • Los campos marcados como Obligatorios deben tener un valor
  • Las fechas pueden estar en formato: DD-MM-YYYY, YYYY-MM-DD, DD/MM/YYYY
  • Los campos únicos (IMEI, Serie) no pueden repetirse en la base de datos
  • Si un cliente no existe, se crea automáticamente con el número proporcionado
  • El archivo debe ser formato Excel (.xlsx o .xls)
  • La primera fila debe contener los encabezados de columna
